K-Closing Alpha

동시호가 정보로 종가 매수·시초가 청산하는 퀀트

개요

15:20에 볼 수 있는 정보만으로 종목 점수를 매기고, 상위 3종목을 종가에 사서 다음 날 시초가에 파는 전략을 연구·자동 실행합니다. 수익률보다 숫자가 부풀려질 곳을 먼저 막았습니다. 미래 정보 차단, 비용 반영, 검증, 중복 주문 방지를 코드로 고정했습니다.

사례

CASE 01K-Closing Alpha개인

판단 시점·확정 종가 컬럼 분리, 미래 정보 차단

  1. 15:20 수집결정_종가 저장
  2. 점수 산정15:20 정보만 사용
  3. 15:30 확정종가는 별도 컬럼
  4. 종가 매수상위 3종목
  5. 시초가 청산다음 날 09:00
P 문제

15:30 확정 종가가 15:20 판단에 섞이면 불가능한 수익이 나옵니다. 두 시각이 10분 차이라 실수하기 쉽습니다.

A 분석
  • 전체 기간 일괄 사용: 누출을 코드로 못 막아 제외
  • 시점별 별도 저장: 누출 검증이 쉬워 선택
A 실행
  • 수집 시점 가격(결정_종가)과 확정 종가(종가) 컬럼 분리
  • 과거 구간은 1분봉에서 15:20 상태 복원
  • 작업 규칙에 '관측 불가능한 가격 체결 가정 금지' 명시
R 결과 코드로 확인

모든 백테스트가 15:20 정보만 사용, 15:30 종가 매수·다음 날 09:00 시초가 청산(연구 문서 기준).

CASE 02K-Closing Alpha개인

1틱 비용 12bp 초과 종목, 순위 전에 제외

P 문제

상위 종목에 호가 간격 큰 저가주가 몰립니다. 1틱이 20~50bp인 종목은 세금·슬리피지 후 손실입니다.

A 분석
  • 상한 6·9·12·15bp, 상한 없음 비교
  • 15bp: Sharpe 2.88로 높지만 매매일 83.3%(12bp는 99.7%)라 제외
  • 12bp 선택: 후보 종목 7.5bp 대비 2.6배, Sharpe도 높음
A 실행
  • 가격대별 호가 단위 표로 1틱 / 현재가 계산, 12bp 초과 제외
  • 거래세 날짜별 세율표, 수수료 증권사 우대율(왕복 약 0.73bp)
  • 상한가 근처 종목 처리도 같은 전략 계약에 포함
R 결과 백테스트

5,000원 미만만 매수 -12.53bp/일, 5,000~20,000원 +24.02bp/일(백테스트, 연구 문서 4절).

CASE 03K-Closing Alpha개인

겹침 제거 CPCV와 교체 게이트, 우연한 모델 차단

  1. 8구간 분할2구간을 시험용
  2. 앞뒤 제외시험 구간 인접 1구간
  3. 28개 분할독립 경로 7개
  4. 주간 재학습신규 모델 생성
  5. 교체 게이트순위 일치도 0.95 이상
P 문제

라벨 기간이 겹치는 데이터를 무작위로 나누면 학습과 평가가 섞입니다. 118개 전략 비교 시 우연히 좋은 전략을 고를 위험도 있습니다.

A 분석
  • 단순 시간 분할: 평가 경로 1개라 운에 좌우, 제외
  • 8구간 중 2구간 시험(CPCV): 평가 경로 다수, 선택
A 실행
  • CPCV(8, 2): 28개 분할, 독립 경로 7개
  • 시험 구간 앞뒤 1구간씩 학습에서 제외
  • 주간 재학습 모델은 최근 20거래일 순위 일치도 0.95 이상 등 통과해야 운영
R 결과 코드로 확인

기준 미달 모델은 운영에 못 올라갑니다. 118개 중 고른 결과라 선택 편향은 남고 보정 결과는 없습니다.

CASE 04K-Closing Alpha개인

주문 선기록과 원장 확인, 중복 주문 차단

  1. 의도 기록INTENT 디스크 저장
  2. 주문 전송SEND 기록
  3. 응답 불확실UNKNOWN 상태
  4. 원장 조회같은 주문 탐색
  5. 채택/종결ADOPT 또는 종결
P 문제

주문 응답이 타임아웃되면 접수 여부를 모릅니다. 재전송하면 이중 매수가 됩니다.

A 분석
  • 재시도 횟수 제한: 접수된 주문을 못 막아 제외
  • 전송 전 기록 + 불확실 시 원장 조회: 선택
A 실행
  • 주문 의도(INTENT)·전송(SEND)을 디스크에 먼저 기록
  • 응답 불확실 시 UNKNOWN, 원장에 같은 주문 있으면 채택(ADOPT), 없을 때만 종결
  • 종가 확정: 시각·장운영 구분코드·현재가와 호가 가격 일치 3조건
R 결과 코드로 확인

상태 전이·채택 로직·종가 확정 함수 구현, 단위 테스트 있음. 실거래 운영 기록은 없음.
