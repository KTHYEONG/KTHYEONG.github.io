Witches-Chat-Core

근거 조항과 함께 답하는 온프레미스 규정 RAG 챗봇

개요

경북대 학사 규정은 HWP·DOCX·PDF로 흩어져 있고, 클라우드 AI에는 규정과 개인정보를 보내기 어렵습니다. 학교 안에서 돌아가는 RAG 챗봇을 팀으로 만들었고, 저는 앞단인 규정 문서의 Markdown 변환과 구조 표시를 맡았습니다.

제가 맡은 일

  • 편·장·절·조·항·호·목을 Markdown 기호로 표시
  • 제어문자·서식 노이즈 제거, 표와 양식을 본문에서 분리
  • DOCX·PDF 변환 속도 개선, 변환 전후 글자 수 점검 로그
  • 오피스·이미지·음성 변환 추가, 청킹용 블록 정보(chunk:block 주석) 전달

청킹·임베딩·소속별 검색, 입력 가드레일, 출력 개인정보 마스킹, Open WebUI 연동, 서버·인프라는 팀원 담당. 블록 정보 형식은 팀원과 함께 정함.

CASE 01Witches-Chat-Core팀

HWP·DOCX·PDF를 Markdown 하나로 통일

  1. 규정 원본HWP·DOCX·PDF
  2. 형식별 변환변환기 등록
  3. 구조 표시조·항·호 기호
  4. 노이즈 정리제어문자·표
  5. 청킹 전달블록 정보 포함
P 문제

규정이 세 형식으로 섞여 있고 조·항·호 계층이 의미를 정합니다. 형식별로 다루면 청킹·검색이 형식에 묶입니다.

A 분석
  • 형식별 청킹: 팀원이 입력을 따로 처리해야 해 제외
  • Markdown: 청킹 표준 입력, 제목·목록·표 표현 가능
  • 팀원 모두 같은 입력 형식 사용 가능
A 실행
  • 형식별 변환기 등록, 같은 출력 구조
  • 초기에는 HWP를 DOCX로 수동 변환
  • 이후 HWP 직접 변환 추가
R 결과 코드로 확인

원본 HWP 20·DOCX 5·PDF 4개를 Markdown 28개로 정리해 청킹 단계에 전달.

CASE 02Witches-Chat-Core팀

원문은 두고 조·항·호 계층 표시만 추가

P 문제

조·항·호·목이 같은 줄글이면 청킹이 조항 중간을 자를 수 있습니다.

A 분석
  • 문장 다듬기·요약: 조항 의미가 달라질 수 있어 제외
  • 원문 유지, 표시만 추가
A 실행
  • 줄 앞머리(제N편/장/절/관, 제N조, ①, 1., 가.) 인식
  • 제목·굵은 소제목·목록으로 표시
  • 학칙 변환 결과에서 장·절 제목, 조 소제목, 항·호 목록 확인
R 결과 코드로 확인

계층이 Markdown 기호로 남아 청킹이 읽을 수 있음. 단서 문장 등 예외 조항은 원문 순서 유지.

CASE 03Witches-Chat-Core팀

표와 신청서 양식을 구분해 본문에서 분리

P 문제

신청서 서식과 빈 칸 많은 표가 본문에 섞이면 검색이 오염되고 청킹이 어렵습니다.

A 분석
  • 표 일괄 처리: 내용 표와 양식 구분 불가, 제외
  • 빈 칸 비율 등 구조 단서와 양식 표현으로 판별
A 실행
  • 빈 칸 많은 다열 표, 양식 표현(예/아니오), 지정 패턴이면 양식 판별
  • 양식은 본문과 따로 변환
  • 청킹이 표를 별도 임베딩 가능
R 결과 코드로 확인

양식 표가 본문과 분리되어 청킹 단계로 전달. 판별 정확도는 미측정.

CASE 04Witches-Chat-Core팀

DOCX·PDF 변환, 라이브러리 대신 직접 읽기

P 문제

큰 규정집의 DOCX·PDF 변환이 느려 규정 수정 후 재변환이 부담이었습니다.

A 분석
  • 병목: python-docx의 객체 생성, pymupdf4llm의 글꼴·정렬·표 처리
  • 옵션 조정보다 필요한 부분만 직접 읽는 방식 선택
A 실행
  • DOCX: XML 노드(본문·표·텍스트 상자) 직접 순회
  • 제어문자 한 번에 제거
  • PDF: PyMuPDF로 표 영역과 본문 블록 분리 읽기
R 결과 운영 기록

커밋 메시지 기준 PDF 변환 약 70초에서 15초. 측정 파일·환경 기록 없는 참고 수치.

한계

  • 전처리 구간 자동 테스트 없음, 글자 수 대조 로그(85% 미만 경고)와 육안 확인
  • 팀 가드레일 결과는 자체 제작 입력 210개 기준, 실제 질의 평가 아님
  • 이미지 변환은 OCR 설치 후 검증 필요
