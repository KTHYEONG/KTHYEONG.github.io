Witches-Chat-Core

근거 조항과 함께 답하는 온프레미스 규정 RAG 챗봇

개요

팀(5명)으로 만든 규정 검색 챗봇(RAG, 검색한 문서를 근거로 답하는 방식)에서, 한글(HWP)·워드(DOCX)·PDF 규정 29개 파일을 Markdown 28개로 바꾸고 조·항 구조를 표시하는 전처리를 맡았습니다. 학사 규정과 개인정보를 클라우드 AI에 보내기 어려워 학교 서버 안(온프레미스)에서 운영하도록 만들었습니다.

CASE 01Witches-Chat-Core팀

세 형식을 Markdown 하나로 통일

P 문제

규정이 세 가지 파일 형식으로 섞여 있고, 조·항·호 계층이 의미를 정합니다. 형식별로 다루면 문서 쪼개기와 검색도 형식마다 따로 만들어야 합니다.

A 분석
  • 형식별 문서 쪼개기는 팀원이 형식마다 따로 처리해야 해 제외
  • Markdown은 문서 쪼개기의 표준 입력이고 제목·목록·표를 표현할 수 있어 팀원 모두 같은 입력으로 사용 가능
A 실행
  • 형식별 변환기를 두되 결과 구조는 동일하게, 처음에는 HWP를 DOCX로 수동 변환하고 이후 직접 변환 추가
  • 큰 규정집은 DOCX·PDF 라이브러리 처리가 느려 XML·블록을 직접 읽는 방식으로 바꿈
R 결과

원본 29개 파일에서 Markdown 28개(규정 24종)를 만들어 문서 쪼개기 단계에 전달했습니다. PDF 변환 시간은 커밋 기록 기준 약 70초에서 15초로 줄었습니다.

CASE 02Witches-Chat-Core팀

원문은 두고 계층 표시만 추가

P 문제

조·항·호·목이 구분 없는 줄글이면 문서를 쪼갤 때 조항 중간이 잘려 의미가 끊길 수 있습니다. 문장을 다듬거나 요약하면 조항 의미가 달라질 수 있어, 원문은 그대로 두고 표시만 붙였습니다.

규정 계층 → Markdown 표시
  • 장 · 절→## 제 N 장, ## 제 N 절제목으로 표시
  • 조→- **제 N 조 ( … )**굵은 소제목 + 목록
  • 항 · 호→① ② / 1.원래 기호 그대로 목록으로
R 결과

학칙 변환 결과에서 장·절 제목, 조 소제목, 항·호 목록으로 계층이 남아 문서 쪼개기 단계가 구조를 읽을 수 있습니다.

CASE 03Witches-Chat-Core팀

표와 신청서 양식 분리

P 문제

신청서 서식과 빈 칸 많은 표가 본문에 섞이면 검색 결과에 불필요한 내용이 끼고 문서 쪼개기도 어렵습니다.

표 처리 방식 비교
모든 표를 같은 방식으로표 모양·양식 표현으로 판별 선택
내용 표와 양식구분할 수 없음구분해 양식만 따로 변환
검색 결과신청서 서식이 본문에 섞임규정 본문과 분리
판별 근거없음빈 칸이 있는 여러 열 표, 양식 표현(예·아니오 등), 정해 둔 글자 패턴
R 결과

양식 표가 본문과 분리되어 문서 쪼개기 단계로 전달됩니다.

CASE 04Witches-Chat-Core팀

변환기와 쪼개기 사이의 블록 정보 주석

  1. 블록 종류 판별변환기
  2. 블록 정보 주석본문 앞에 JSON 주석
  3. 주석 읽기문서 쪼개기 단계
  4. 블록 단위 분할구간 정보 활용
P 문제

문서 쪼개기 단계는 각 조각이 제목인지 목록인지 표인지 알아야 하는데, Markdown 본문만으로는 구분이 어렵습니다.

A 실행
  • 변환기가 각 블록에 chunk:block JSON 주석을 붙여 넘기고, 문서 쪼개기 쪽이 같은 주석을 읽어 분할(형식은 팀원과 함께 정함)
  • 텍스트·엑셀·파워포인트·이미지·음성 변환도 같은 경로로 연결
R 결과

여러 형식이 같은 주석 형식으로 문서 쪼개기 단계에 전달됩니다.

한계

  • 전처리 구간에는 자동 테스트가 없고, 변환 결과는 글자 수 대조 로그(85% 미만이면 경고, 중단은 안 함)와 눈으로 확인
  • 구조 표시와 표·양식 판별의 정확도를 정답과 대조해 측정하지 않았음
  • 팀 악성 질문 차단 결과는 직접 만든 입력 210개(악성 130개 포함) 기준이고 실제 질의 평가가 아님. 챗봇 전체의 답변 정확도·근거 일치 수치는 없음
  • 변환·점검은 24종 규정, 소량 문서로 확인해 속도 개선의 체감 근거가 약하고, 속도 수치는 측정 환경 기록 없는 커밋 메시지 기준임. 이미지 변환은 OCR 설치 후 검증 필요
