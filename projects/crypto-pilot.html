Crypto Pilot

바이낸스 선물 전략 검증과 모의 자동 집행

개요

바이낸스 무기한 선물의 백테스트부터 24시간 자동 집행까지 한 저장소에서 다룹니다. 미래 정보 사용, 체결 비용, 강제청산, 반복 시험 편향을 코드에서 줄였습니다. 집행 데몬은 모의(paper) 모드이며 모든 수익률은 재현 시뮬레이션입니다.

CASE 01Crypto Pilot개인

강제청산 규칙을 넣은 계좌 시뮬레이션으로 레버리지 결정

  1. 수익 분포시점별 갱신
  2. 배율 선택기대 성장 최대
  3. 상한 적용10배·증거금 90%
  4. 계좌 시뮬유지증거금·펀딩비
  5. 청산 확인강제청산 여부
P 문제

레버리지를 높이면 수익은 커 보여도 급락 때 유지증거금이 모자라면 강제청산됩니다. 비중만 계산하는 백테스트는 이를 반영하지 못합니다.

A 분석
  • 전체 기간 수익으로 고정 배율 선택: 미래 정보 사용, 제외
  • 과거 수익만으로 매일 배율 재산정: 당시 정보만 사용, 선택
  • 청산 확인에는 증거금 규칙 계좌 시뮬레이터 필요
A 실행
  • 시점별 수익 분포로 기대 로그 성장 최대 배율 선택
  • 상한 10배, 증거금 한도 초기 증거금의 90%
  • 유지증거금 구간·펀딩비·수수료·최소 주문 단위 반영
R 결과 재현 시뮬레이션

재현 시뮬레이션($1,000, 2021-04 ~ 2026-10)에서 강제청산 0회, MDD -51.2%. 평균 배율 약 3.8배라 낙폭이 큰 점은 한계로 기록.

CASE 02Crypto Pilot개인

종가 체결 가정 대신 3분봉 지정가 체결 재현

  1. 주문 발생지정가 주문
  2. 3분봉 순회30분 구간
  3. 체결 판정지나간 만큼만
  4. 월 단위 이월보유·대기 주문
  5. 동치 검증전체 처리와 비교
P 문제

1시간봉 종가 체결 가정은 수수료, 호가 차이, 지정가 미체결을 빼 실제와 결과가 다릅니다.

A 분석
  • 시장가(테이커): 수수료 6bp(1bp=0.01%), 제외
  • 지정가(메이커): 수수료 2bp, 체결 여부를 가격 경로로 판정
  • 5.25년치 3분봉: 월 단위 분할 처리, 전체 처리와 동일 결과 필요
A 실행
  • 주문 후 3분봉 10개(30분) 동안 지정가를 지난 만큼만 체결
  • 월 단위로 읽으며 보유 수량·대기 주문 이월
  • 월 단위와 전체 처리 결과를 동치 테스트로 확인
R 결과 코드로 확인

지정가 중심 집행을 계좌 시뮬레이션 기본값으로 채택. 월 단위 처리의 동일성은 테스트로 검증.

CASE 03Crypto Pilot개인

반복 시험 편향, 시험 횟수 기록과 DSR로 보정

  1. 후보 시험매번 기록 남김
  2. 횟수 반영52줄 기록
  3. DSR 판정0.95 이상만
  4. 매니페스트accept 기록
  5. 홀드아웃07-01 이후 분리
P 문제

후보를 계속 바꿔 시험하면 우연히 좋은 결과를 고르게 됩니다.

A 분석
  • 최종 결과 하나만 판단: 시도 횟수 은폐, 제외
  • 시험 횟수만큼 샤프지수를 깎는 DSR을 승격 기준으로 채택
  • 설계 데이터와 홀드아웃 분리로 사후 확인 확보
A 실행
  • 시험마다 기록(52줄), DSR의 시도 횟수로 반영
  • DSR 0.95 이상만 매니페스트 승격, 기준값·판정 기록
  • 설계 데이터 2026-07-01까지, 이후는 홀드아웃
R 결과 백테스트

매니페스트에 dsr_min 0.95, accept 기록. 홀드아웃 포함 CAGR +212.7%, 설계 구간 +220.4%와 유사. 홀드아웃은 3개월로 짧음.

CASE 04Crypto Pilot개인

주문 시각과 겹치지 않는 무중단 배포

  1. 코드 변경수집 코드 수정
  2. 지문 비교AST 해시
  3. 대기 확인결정 시각·락
  4. 슬롯 교대Blue/Green
P 문제

정해진 주문 시각 전후에 배포하면 주문이 지연되거나 시세 수집이 끊길 수 있습니다.

A 분석
  • 컨테이너 재시작: 웹소켓 단절로 데이터 공백, 제외
  • 사람이 시각을 피하는 방식: 실수 가능, 제외
  • 코드 변경 시에만 교대, 결정 시각 전후 대기 자동 규칙 선택
A 실행
  • 수집 데몬 Blue/Green 두 슬롯 교대
  • 수집 코드 AST 정규화 해시로 변경 여부 판단
  • 결정 시각 전후·라이브 락 중 배포 대기
R 결과 코드로 확인

지문 계산과 대기 조건을 단위 테스트로 검증. 배포 중단 시간 실측치는 없음.

한계

  • 모든 수익률은 재현 시뮬레이션, 실제 운용 결과 아님. 집행은 paper 모드.
  • 평균 배율 약 3.8배, MDD -51%로 실제 운용에서 버티기 어려움.
  • 펀딩 손익의 약 91%가 상위 5개 종목에 집중, 홀드아웃은 3개월.
