OIBC 2026

태양광 발전량 예측과 VPP 배정을 규칙 위반 없이 비교하는 파이프라인

개요

2026 POSTECH OIBC 빅데이터 경진대회에 참가해, 태양광 발전소 253곳을 두 개의 가상발전소(VPP, 발전소 묶음)로 나누고 각 VPP의 하루 전 시간별 발전량을 예측하는 파이프라인을 만들었습니다. 점수보다 규칙을 어기지 않는 것을 먼저 두고, 예측 마감 이후 정보 차단, 정산 기준 평가, 사전에 정한 채택 규칙을 코드로 고정했습니다. 제출 기간(11.2~11.13) 중이라 최종 순위는 정해지지 않았습니다.

CASE 01OIBC 2026개인

예측 마감 이후 정보 차단

마감 게이트·시간축·정산 규칙을 단위 테스트로 고정했습니다.
  1. 원천 예보발행 시각 포함
  2. 발행 시각 확인대상 운영일 마감과 비교
  3. 마감 이후면 중단오류로 멈춤
  4. 파생 테이블마감 이전 정보만
  5. 특성 패널모델 입력
P 문제

전날 17:00 이후의 정보를 쓰면 대회 규칙 위반인데, 시계열 데이터는 실수로 미래 정보가 섞이기 쉽습니다.

  • 전날 17:00예측 마감, 이후 발행된 예보를 쓰면 오류로 중단
  • KST 오른쪽 닫힘모든 시각 통일, 01:00은 00~01시
  • 테스트 14개게이트 모듈 단위 테스트
A 분석
  • 모델 쪽에서 조심하는 방식은 특성이 늘수록 빈틈이 생겨 제외하고, 데이터를 파생하는 단계에서 막는 방식을 채택
  • 시각 표기가 섞이면 한 시간 어긋나 미래 정보가 들어갈 수 있어 시각 규칙부터 통일
A 실행
  • 예보 발행 시각이 대상 운영일의 마감보다 늦으면 기본값으로 대체하지 않고 오류로 중단
  • 마감 이후 예보를 망가뜨려도 이전 날의 특성이 바뀌지 않는지 테스트
R 결과

마감 게이트·시간축·정산 규칙을 단위 테스트로 고정했습니다.

CASE 02OIBC 2026개인

사전 채택 규칙으로 실험 판정

판정 규칙과 기록 구조를 코드로 구현했습니다.
P 문제

같은 검증 데이터로 실험을 반복하면 우연히 좋아 보이는 설정을 고르게 됩니다. 리더보드 점수에 맞춰 고치는 것도 같은 문제입니다.

  • 신뢰구간 0 제외7일 단위 재표본(부트스트랩)
  • 시드 잡음의 2배 초과시드를 바꿔 흔들리는 폭보다 큰 개선만
  • 최소 1% 개선정산 벌점 기준
  • 분기 70% 이상분기별로 개선된 비율
A 분석
  • 시드를 바꾸면 결과가 흔들려, 그 흔들림보다 큰 개선인지 따져야 함
  • 코드 버전이나 입력이 다른 실행끼리의 비교는 의미 없음
A 실행
  • 시간순 폴드 2개와 시드 3개, 폴드 사이 1일 간격으로 검증
  • 실험마다 가설·설정·시드·패널 해시를 기록하고 채택·기각·판정 불가 중 하나로 남김
R 결과

판정 규칙과 기록 구조를 코드로 구현했습니다.
