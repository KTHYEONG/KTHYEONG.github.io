SaveTax

시중가보다 비싼 납품 물품을 찾는 감사 도구

개요

공공조달 공개 자료에서 시중가보다 비싸게 집행된 금액을 찾는 해커톤 참가작입니다. 중복 정리, 4종 비교 근거 수집, 사람 승인 후 제출 순서로 풀었습니다.

사례

CASE 01SaveTax개인

중복 주문 합계 보정, 불일치는 중단

  1. 로드Parquet 직접 조회
  2. 무결성 검사dlv_key별 일치 확인
  3. 불일치 중단오류로 멈춤
  4. 정규화 뷰주문당 1건
  5. 집계빈 값은 0 아님
P 문제

같은 주문이 여러 물품에 반복돼 단순 합계가 부풀려집니다. 집계가 틀리면 이후 판정이 모두 어긋납니다.

A 분석
  • 합계 전 중복 제거 필요
  • 계약번호·금액이 다르면 합치지 않음
  • 주문 없는 물품(약 71%)은 0이 아닌 빈 값, 0 채움은 평균 왜곡으로 제외
  • 불일치를 넘기지 않고 로드 시점에 중단 선택
A 실행
  • DuckDB로 Parquet 직접 조회, dlv_key별 일치 검사
  • 주문당 1건 정규화 뷰 생성, 불일치 시 오류 중단
  • 빈 값은 0으로 바꾸지 않고 유지
R 결과

주문당 1건 뷰 사용, 불일치 데이터는 중단. 약 24%는 대회 안내 수치.

CASE 02SaveTax개인

전용 품목은 부품 가격 합산으로 비교, 출처 기록

  1. 사양 정리CPU·메모리·SSD
  2. 부품 가격쇼핑몰 2곳 근거
  3. 공임 가산표준품셈 적용
  4. 합산 원가기준가 산출
  5. 제보 본문출처·합산식 기재
P 문제

PC, 패치패널, 서버랙은 전용 모델이라 쇼핑몰에 같은 제품이 없습니다. 시중가 비교로는 후보에서 빠집니다.

A 분석
  • 동급 사양 부품 가격 합계로 대체 비교
  • 근거가 약해 보이므로 쇼핑몰·페이지 출처를 제보에 기재
  • 근거 종류별 기준이 달라 4종으로 나눠 배율 분리
A 실행
  • 사양 정리 후 시판 부품 가격 합산, 설치 품목은 표준품셈 공임 가산
  • 부품별 쇼핑몰 2곳 근거, 1.2~1.3배 구간은 두 번째 가격으로 재확인
  • 기준 배율(cross·agency·recipe 1.20, retail 1.10) 설정 한곳에 통합
R 결과

레시피 부품 정의 32개, 쇼핑몰 검색 규칙 18곳. 제보 본문에 출처와 합산식 포함.

CASE 03SaveTax개인

옵션 혼재 계약, 오탐 줄이는 기준 설정

  1. 옵션 확인단가가 여럿인지
  2. 대표 단가가장 높은 값
  3. 계열 분리다른 블록은 비교 안 함
  4. 시점 검증납품일에 유효한지
P 문제

단가 다른 옵션이 섞인 계약에서 비싼 본품을 싼 옵션과 비교해 허위 후보가 나옵니다.

A 분석
  • 평균·최저 단가 기준은 과다 집행처럼 보이는 후보 증가로 제외
  • 최고 대표 단가 기준은 후보 감소, 제보 횟수 한도 고려해 선택
  • 비교 단가의 납품일 유효 여부 별도 확인
A 실행
  • 옵션 다수면 최고 대표 단가 기준
  • 순번 블록 다른 계열(일반형·내진형)은 비교 제외
  • 변경계약일·납품 이력으로 단가 유효 시점 확인
R 결과

후보를 덜 내는 방향으로 설계, 문턱마다 단위 테스트.

CASE 04SaveTax개인

재실행해도 같은 건 두 번 제출 안 됨

  1. 사람 승인내용 해시에 묶음
  2. 가격 재확인제출 직전
  3. 원장 기록전송 전에 먼저
  4. 전송고유 키 포함
  5. 재실행 확인미결 건 서버 조회
P 문제

제보 횟수 한도 때문에 재실행하면 같은 건이 이중 차감될 수 있습니다. 토큰 유출도 막아야 합니다.

A 분석
  • 전송 후 기록은 '보냈는데 기록 없음' 상태가 생겨 복구 불가
  • 전송 전 기록은 재실행 때 서버 조회로 확인 가능, 이쪽 선택
  • 승인은 사람이 하고, 내용 변경 시 무효가 되도록 내용에 결합
A 실행
  • 요청 고유 키를 원장에 선기록(flock 잠금, fsync 반영), 재실행 시 미결 건 확인
  • 승인을 제출 내용 SHA-256 해시에 결합, 제출 직전 가격 재확인
  • 토큰은 공식 호스트만 전송, 리다이렉트 불가, 로그 마스킹
R 결과

재실행해도 같은 건을 다시 보내지 않는 구조. 해당 경로는 단위 테스트 있음.

한계

  • 과다 집행 판정은 시중가 비교 추정, 심사에서 근거 부족일 수 있음.
  • 대회 결과는 확정 전이라 싣지 않음.
